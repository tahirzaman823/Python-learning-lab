# 1. What is Python?

## Definition

Python is a high-level, interpreted programming language known for its simple syntax and human-like readability. It acts as an abstraction bridge, hiding complex machine-level mechanics so developers can write logical code easily.

## Syntax

```python
print("Hello, World!")


# Calculating a sum in Python
result = 5 + 5
print(result)  # Output: 10

## Important Points

* **High-Level Language:** Far easier to read and write than low-level languages (like Assembly or C) or binary machine code (1s and 0s).
* **Interpreted Nature:** Code is executed line-by-line rather than requiring manual compilation before execution.
* **Versatile:** Used for web development, automation, data science, AI, and robotics.
```
