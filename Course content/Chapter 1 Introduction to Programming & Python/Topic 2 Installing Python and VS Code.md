# Installing Python and VS Code

## Installing Python

1. **Download Python**
   - Visit the official Python website: [python.org](https://www.python.org/).
   - Download the latest version for your operating system (Windows, macOS, or Linux).

2. **Install Python**
   - Run the installer and ensure you check the box to **Add Python to PATH** (important for running Python from the command line).

3. **Verify Installation**
   - Open a terminal or command prompt and type:

```bash
     python --version
```

   - This should display the installed Python version (e.g., `Python 3.13.5`).

## Choosing an IDE

### What is an IDE?

An Integrated Development Environment (IDE) is a software application that provides tools for writing, testing, and debugging code.

### Popular Python IDEs

- **VS Code:** Lightweight, customizable, and supports extensions for Python. *(We will use this one as our primary IDE)*
- **PyCharm:** Powerful IDE with advanced features for professional developers.
- **Jupyter Notebook:** Great for data science and interactive coding.
- **IDLE:** Comes pre-installed with Python; good for beginners.
